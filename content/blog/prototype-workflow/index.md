This is a **prototype post**, not an announcement. It demonstrates the format SEEM can use to share a conference presentation, workshop, project milestone, visitor, student achievement, or software release.

A normal update should include a clear title, date, one or two paragraphs, an approved visual when available, and links to the relevant paper, code, slides, or event.
